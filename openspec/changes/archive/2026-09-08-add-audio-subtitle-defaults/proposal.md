## Why

На реальном Kodi выбранный звуковой поток для видео с несколькими дорожками не тот,
который нужен пользователю: для видео с русским оригиналом по умолчанию играет
английская сгенерированная («dubbed/auto») дорожка, а оригинальную нельзя выбрать по
умолчанию. Кроме того, субтитры в текущей реализации вообще не работают: yt-dlp
отдаёт их отдельным контентом (`subtitles`/`automatic_captions`), но они не
привязываются к ListItem, поэтому в плеере их нет. Пользователю нужны настройки по
умолчанию: аудиодорожка (Auto / Original / конкретный язык) и субтитры (вкл/выкл),
а также рабочая передача субтитров в плеер.

## What Changes

- В `resources/settings.xml` добавляются настройки:
  - «Default audio» (Auto/Best = как сейчас, Original = оригинальная дорожка, либо
    конкретный язык, например `ru`, `en-US`);
  - «Subtitles» (Off / On), включающая/выключающая субтитры по умолчанию.
- В `default.py::play_stream` (или рядом) при сборке ListItem:
  - для HLS-пути передаётся предпочитаемый язык аудио через свойства InputStream
    Adaptive, если настройка задана явно (Original/язык), иначе — поведение как
    сейчас (Auto);
  - к ListItem привязываются субтитры, найденные в `info` (из `subtitles` +
    `automatic_captions`), с учётом их формата (`vtt`/`srv3`/`json3`) и настройки
    вкл/выкл.
- В `resources/lib/resolver.py` добавляются чистые helper-функции для работы с
  аудио/субтитрами (перечисление дорожек, определение оригинала, выбор vtt-ссылок),
  тестируемые на desktop без сети.
- Происходит починка субтитров: субтитры реально появляются в плеере Kodi, а не
  «вообще не работают».
- Затронутые path'ы воспроизведения: `play`, прямой `?video_id=..`, `play_quality`
  (выбранное качество не влияет на аудио/субтитры).

## Capabilities

### New Capabilities

- `playback/audio-subtitle-defaults`: настройки аудиодорожки и субтитров по
  умолчанию, выбор дорожек и передача субтитров в плеер, чтобы пользователь мог
  выбрать оригинальный звук и включать/выключать субтитры.

### Modified Capabilities

Нет. В `openspec/specs/` ещё нет ни одной синхронизированной спецификации; это
вторая capability проекта (первая `playback/quality-selection` находится только в
delta ещё не заархивированного change).

## Impact

- `resources/settings.xml` — новые пункты «Default audio» и «Subtitles».
- `default.py` — чтение настроек, передача языка аудио в свойства ISA, привязка
  субтитров к ListItem в `play_stream`.
- `resources/lib/resolver.py` — чистые helper-функции (аудио-дорожки, субтитры),
  xbmc-free.
- `tests/` — desktop-тесты на новые helper-функции + shim-тесты на проброс свойств.
- Без изменений: вендоренный `yt_dlp`, `ytlib`, движок воспроизведения (HLS/ISA),
  логика выбора качества из прошлого change.
