## Why

OuterTube — приватный YouTube-клиент для Kodi в духе NewPipe. Сейчас видео всегда
воспроизводится в том качестве, которое выбрал резолвер/InputStream Adaptive, —
пользователь не может его поменять. NewPipe даёт пользователю выбирать качество
видео; мы хотим то же самое. Это первый шаг более широкой «NewPipe-дорожной карты»
(качество, подписки, локальная история, локальные плейлисты), каждый пункт которой
будет оформлен отдельным change. Данный change покрывает только выбор качества.

## What Changes

- Добавляется возможность перечислить доступные для видео качества (высоты из
  форматов yt-dlp), чтобы предложить их пользователю.
- В поток воспроизведения добавляется выбор качества: пользователь может указать
  желаемое качество (Auto/Best, 144p–2160p) перед запуском/во время запуска видео.
- При воспроизведении выбранное качество применяется к потоку InputStream Adaptive
  (ограничение максимального разрешения), сохраняя дефолтное поведение Auto/Best,
  когда пользователь ничего не выбрал.
- Добавляется настройка аддона «Качество видео по умолчанию», используемая, когда
  пользователь не выбирает качество для конкретного видео.
- Модуль `resolver` остаётся xbmc-free (чистые функции) и покрыт desktop-тестами;
  UI-склейка остаётся в `default.py`.

### Non-goals (будущие изменения)

Подписки, локальная история просмотра и локальные плейлисты — отдельные будущие
OpenSpec-изменения дорожной карты NewPipe. Здесь они не реализуются.

## Capabilities

### New Capabilities

- `playback/quality-selection`: требования к возможности выбора/ограничения качества
  воспроизведения видео (перечисление доступных качеств, выбор, применение к потоку,
  настройка качества по умолчанию).

### Modified Capabilities

Нет. В `openspec/specs/` пока нет ни одной спецификации — это первая capability проекта.

## Impact

- `resources/lib/resolver.py` — новые чистые helper-функции: перечисление доступных
  качеств по форматам и применение выбранного качества (xbmc-free, тестируемо на desktop).
- `default.py` — роутер/UI: выбор качества, новый action-параметр, несущий выбранное
  качество в `play`, проброс свойства ограничения разрешения на ListItem для
  InputStream Adaptive.
- `resources/settings.xml` — новый диалог настроек аддона с пунктом «Качество видео
  по умолчанию» (файла настроек сейчас нет).
- `tests/` — расширение desktop-тестов для новых helper-функций резолвера и
  поведения роутера (через Kodi-shim).
- Без изменений: вендоренный `yt_dlp`, поведение каталога (`ytlib`), зависимости
  движка воспроизведения.
